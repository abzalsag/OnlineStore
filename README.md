# 🛒 OnlineStore

Backend for an online store, written in **Go**. The project is built step by step: starting with a clean REST API on top of PostgreSQL and Redis, then growing into a production-like system with gRPC, Kafka, and full observability.

## ✨ Features

- REST API for the core store domain: users, products, categories, carts, orders
- PostgreSQL as the primary data store with versioned migrations
- Type-safe database access generated by **sqlc**
- Redis for caching and sessions
- Fully containerized local environment with Docker Compose
- Clean, layered architecture (handler → service → repository)

## 🚀 Getting Started

### Prerequisites

- [Go](https://go.dev/dl/) 1.22+
- [Docker](https://docs.docker.com/get-docker/) and Docker Compose
- [golang-migrate](https://github.com/golang-migrate/migrate)
- [sqlc](https://docs.sqlc.dev/en/latest/overview/install.html)
- `make` (optional, but recommended)

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/OnlineStore.git
cd OnlineStore
```

### 2. Set up environment variables

```bash
cp .env.example .env
```

### 3. Start the infrastructure and the app

```bash
docker compose up -d --build
```

This starts PostgreSQL, Redis, and the API service.

### 4. Apply migrations

```bash
make migrate-up
```

### 5. Check that it works

```bash
curl http://localhost:8080/health
```

## ⚙️ Configuration

The app is configured through environment variables:

| Variable | Description | Example |
|---|---|---|
| `APP_PORT` | HTTP server port | `8080` |
| `APP_ENV` | Environment (`local`, `dev`, `prod`) | `local` |
| `POSTGRES_HOST` | PostgreSQL host | `localhost` |
| `POSTGRES_PORT` | PostgreSQL port | `5432` |
| `POSTGRES_USER` | PostgreSQL user | `postgres` |
| `POSTGRES_PASSWORD` | PostgreSQL password | `postgres` |
| `POSTGRES_DB` | Database name | `onlinestore` |
| `REDIS_ADDR` | Redis address | `localhost:6379` |
| `REDIS_PASSWORD` | Redis password | *(empty)* |
| `JWT_SECRET` | Secret for signing tokens | `change-me` |

## 🗄 Database Migrations

Migrations are managed with **golang-migrate** and live in `db/migrations`.

```bash
# Create a new migration
migrate create -ext sql -dir db/migrations -seq create_products_table

# Apply all migrations
migrate -path db/migrations -database "$DATABASE_URL" up

# Roll back the last migration
migrate -path db/migrations -database "$DATABASE_URL" down 1
```

## 🧬 Code Generation (sqlc)

Write SQL queries in `db/queries/`, then generate type-safe Go code:

```bash
sqlc generate
```

Generated code is placed in `internal/db/`. Do not edit it manually.

## 🌐 API Overview

Base URL: `http://localhost:8080/api/v1`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/health` | Health check |
| POST | `/auth/register` | Register a new user |
| POST | `/auth/login` | Log in |
| GET | `/products` | List products |
| GET | `/products/{id}` | Get product by ID |
| POST | `/products` | Create product (admin) |
| PUT | `/products/{id}` | Update product (admin) |
| DELETE | `/products/{id}` | Delete product (admin) |
| GET | `/cart` | Get current cart |
| POST | `/cart/items` | Add item to cart |
| POST | `/orders` | Create order |
| GET | `/orders` | List user orders |
